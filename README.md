# EcoRadar
Earth observation and environmental monitoring platform using NASA satellite data, including NISAR observations.
🌍 EcoRadar

Exploring Earth's changes through satellite data.

EcoRadar is a project built to explore how we can use satellite technology to better understand our planet.

The idea is simple: make Earth observation data easier to see, explore, and understand.

I'm developing EcoRadar using NASA satellite data, including real observations from the NISAR mission.

What can it do?

- Visualize satellite data on an interactive map.
- Explore environmental conditions in different regions.
- Compare satellite observations from different dates.
- View raster data and statistics.
- Explore simulated environmental scenarios.

Real NASA Data

For this project, I'm using two NASA NISAR observations of Greenland:

- October 22, 2026
- November 3, 2026

Both observations use the HHHH layer from the NISAR Level-2 GCOV product.

I'm using them to experiment with comparing satellite observations over the same area.

Why EcoRadar?

Earth is constantly changing, and satellite data gives us a way to observe those changes from space.

I wanted to build something that makes this kind of data more accessible and interesting to explore.

Data Sources

- "NASA NISAR" (https://nisar.jpl.nasa.gov/)
- "NASA Alaska Satellite Facility" (https://search.asf.alaska.edu/)

A Note About the Data

The project is still under development. The satellite comparison is experimental, and differences between observations do not automatically prove environmental change.

Built for the NASA Space Apps Challenge.
